# Анализ в SQLite

[English](README.md) · [Русский](README.ru.md)

Из корня проекта выполните команду.

```powershell
python sql/create_database.py
```

Python использует встроенный модуль `sqlite3`. Скрипт читает пять CSV из папки `data/` и создаёт `sql/ecommerce.db`. Для пересборки базы закройте её в программе просмотра и запустите скрипт повторно.

Откройте `ecommerce.db` в SQLite-клиенте и по очереди выполните десять запросов из [sales_queries.sql](sales_queries.sql). Если установлен консольный SQLite, весь файл можно выполнить из корня проекта одной командой.

```powershell
sqlite3 -header -column sql/ecommerce.db ".read sql/sales_queries.sql"
```

## Как устроены расчёты

- **Запросы 1, 2 и 8.** Одна строка в `orders` соответствует одному заказу. Соединение с `customers` по уникальному `customer_id` добавляет штат покупателя и сохраняет число строк.
- **Запросы 3-7.** Одна строка в `order_items` соответствует одной товарной позиции. Стоимость доставленных товаров в BRL считается суммой `price`. При расчёте среднего чека `COUNT(DISTINCT order_id)` учитывает каждый заказ один раз.
- **Запросы 6 и 7.** Соединение со справочником переводов сохраняет все товарные позиции. `COALESCE` выбирает английское название категории, исходное название или `Uncategorized`.
- **Запросы 9 и 10.** Конструкция `WITH` задаёт имя промежуточному результату. Запрос 9 сначала считает позиции в каждом доставленном заказе, затем усредняет эти количества. Запрос 10 сначала считает продажи за каждый месяц с доставленными продажами, затем сравнивает значения со средним за эти месяцы.
