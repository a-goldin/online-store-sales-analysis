# Отчёт Power BI

[English](README.md) · [Русский](README.ru.md)

Откройте [sales_dashboard.pbix](sales_dashboard.pbix) в Power BI Desktop. Данные уже встроены. При первом открытии выбран весь период, за который есть доставленные заказы.

## Обновление на другом компьютере

Поместите пять CSV Olist в папку `data/` и выполните команды из корня проекта.

```powershell
python sql/create_database.py
python powerbi/prepare_data.py
```

В Power BI Desktop откройте **Преобразование данных → Изменить параметры** (**Transform data → Edit parameters**), укажите полный путь к `powerbi/sales.csv` в параметре `SalesCsvPath`, примените изменение и обновите отчёт. Запрос читает CSV в кодировке UTF-8. `OrderDate` содержит дату оформления заказа, а `ItemPrice` хранится как число с фиксированной точностью в BRL.

## Страницы отчёта

| Страница | Срезы | Показатели и графики |
| --- | --- | --- |
| Sales Overview | Дата оформления и штат покупателя | Четыре карточки KPI, продажи по месяцам, десять ведущих категорий по стоимости товаров и продажи по штатам |
| Product Analysis | Дата оформления и категория | Три карточки KPI, рейтинги категорий по количеству позиций и стоимости, доли категорий и помесячная динамика выбранных категорий |

На странице Product Analysis срез категории фильтрует всю страницу. Выбор категории в рейтинге или на диаграмме долей (treemap) фильтрует помесячный график. При наведении на прямоугольник видна доля категории в продажах текущей выборки.

В отчёте одна таблица с одной строкой на доставленную позицию. Число заказов считается по уникальным `OrderID`, число покупателей по уникальным `CustomerID`. Количество заказов по всем статусам и разбивка по статусам доступны в SQL, Pandas и Excel. [Описание мер DAX](measures.ru.md).
